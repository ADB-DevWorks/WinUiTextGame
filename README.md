# WinUiTextGame Engine

A modular **text‑based game engine** built with **C#** and **WinUI 3**.  
This project is evolving from a simple text adventure into a fully extensible engine designed to power narrative‑driven games, interactive fiction, and branching story experiences.

This README will expand as the engine grows.

## Overview

The WinUiTextGame Engine aims to provide a flexible framework for building text‑based games with modern Windows UI features. The engine focuses on:

- Clean separation between UI and game logic  
- Modular scene and dialogue systems  
- Event‑driven interactions  
- Extensible architecture for creators  
- A polished, responsive WinUI interface  

This project is actively being developed and will grow into a full creator‑friendly toolkit.

---

## Engine Goals

### Core Objectives
- Provide a structured way to define:
  - Scenes  
  - Choices  
  - Dialogue  
  - Game states  
  - Player attributes  

- Allow creators to build games without modifying engine code  
- Support modular content loading (JSON, XML, or custom formats)  
- Offer a clean, modern UI for playing and testing games

## How to Run

### Prerequisites
- Windows 10/11  
- Visual Studio 2022  
- .NET Desktop Development workload  
- WinUI 3 templates installed  

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/ADB-DevWorks/WinUiTextGame.git
   ```
2. Open the solution:
   ```
   WinUiTextGame.slnx
   ```
3. Build and run the project.
